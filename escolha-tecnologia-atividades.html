Quem faz o quê em um sistema?

Interface Web→n8n: eventos / integração→FastAPI: regras / autorização→SDK / runtime: decisões do agente→LLM: interpretação→PostgreSQL: estado / auditoria

Uma arquitetura pode combinar tecnologias. O n8n pode receber um Webhook e chamar via HTTP um agente implementado no Agents SDK. O n8n coordena o processo externo; o Runner coordena o ciclo do agente. FastAPI valida autorização e PostgreSQL persiste histórico. Não coloque LLM em regras administrativas.

Regras de escolha para os grupos

  1. Descrever tarefa e entradas/saídas.
  2. Separar passos determinísticos de decisões abertas.
  3. Escolher o menor runtime capaz de resolver a tarefa.
  4. Escolher LLM só após medir necessidade e restrições.
  5. Definir ferramentas, permissões e validação humana.
  6. Provar funcionamento com dados sintéticos e comparar a um baseline.
