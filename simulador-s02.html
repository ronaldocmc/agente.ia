Início / Simuladores

S02 — Viabilidade de arquiteturas

Qual arquitetura cabe no orçamento? Laboratório interativo de engenharia de agentes. Valores hipotéticos, não preços de mercado.

Parâmetros

Resultados da estimativa

Como o cálculo funciona

Gerenciada = assinatura + excedentes. Própria com API = hospedagem + API + administração. Local = energia + manutenção + administração + hardware/horizonte. Híbrida = local + API × fração externa. Total no horizonte = mensal equivalente × meses.

Exemplo didático

Compare serviço gerenciado, runtime próprio com API, modelo local e arquitetura híbrida com orçamento de R$ 200.

Atividade experimental

Varie o horizonte e o percentual de chamadas externas. Exporte os cenários e compare alternativas no orientador.

Exporte os cenários JSON antes e depois da alteração. Registre previsão, resultado, interpretação e limitações; não apresente estimativas como medições reais.

Limitações

Custo equivalente sem juros, valor residual, impostos ou diferenças de qualidade e capacidade. Custos de administração e outros serviços precisam ser informados; não equivale a cotação de fornecedores.
