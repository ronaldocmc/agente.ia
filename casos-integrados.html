Segundo Cérebro: conhecimento e memória persistente para agentes

Uma entrada única para os estudos de caso preservados e as aplicações novas, com ligação para fichas tecnológicas, laboratórios e conceitos.

Como estudar os exemplos

Cada caso informa o que pode ser executado por regras, o que pode justificar um agente, tecnologias candidatas, limites e testes. A escolha não exige que todos os componentes sejam agentes.

Aplicações com equipes que constroem e operam sistemas

CRM com atendimento multicanal

Consolidar captação de leads, conversas de WhatsApp e Instagram, histórico comercial e acompanhamento do funil de vendas.

Agentes: Agente comercial interpreta intenção e consulta histórico; agente de atendimento formula resposta; coordenador encaminha casos complexos.

Plataforma Base com equipes e agentes

Criar a base reutilizável para aplicações institucionais, com autenticação, equipes, RBAC, painel, contratos e integração de agentes.

Agentes: Equipe de desenvolvimento (arquiteto, implementador, UX, QA, DevOps) constrói o sistema; agentes operacionais atuam depois de implantado.

Ler o caso completo →

Fábrica de vídeos assistida por IA

Produzir peças audiovisuais com roteiro, narração, cenas, edição e publicação supervisionada.

Agentes: Roteirista prepara texto; revisor verifica fontes; produtor coordena APIs de voz/vídeo; editor humano aprova versão final.

Ler o caso completo →

Dashboard financeiro e interpretação de dados

Consolidar receitas, despesas, conciliação, projeções e explicações de indicadores sem delegar cálculos ao LLM.

Agentes: Agente analista formula perguntas e hipóteses; agente conciliador sugere possíveis correspondências; regras calculam saldos e projeções.

12 aplicações de automação inteligente e agentes

01. Inscrições em cursos

Fluxo: Google Forms → validação → Sheets → confirmação

Tecnologias: n8n, Forms, Sheets, Apps Script

Quando usar agente: Interpretar solicitações livres ou resolver exceções; validação de campos continua determinística

Abrir exemplo detalhado →

02. Consulta de certificados

Fluxo: Identificação → consulta autorizada → regra institucional → resposta

Tecnologias: Python, PostgreSQL, n8n, MCP

Quando usar agente: Interpretar o pedido e chamar ferramenta; não decidir a aptidão à revelia da regra

Abrir exemplo detalhado →

03. Síntese documental

Fluxo: Documento → extração → síntese → revisão

Tecnologias: LLM, Ollama, RAG, pgvector

Quando usar agente: Escolher fontes, solicitar complementos e sinalizar inconsistência

Abrir exemplo detalhado →

04. Assistência didática

Fluxo: Dúvida → classificação → resposta com referências

Tecnologias: RAG, Ollama, Agents SDK

Quando usar agente: Consultar ferramenta pedagógica e escalar para docente

Abrir exemplo detalhado →

05. Consulta de estoque

Fluxo: ERP → SQL → disponibilidade

Tecnologias: n8n, APIs, PostgreSQL

Quando usar agente: Investigar inconsistências e combinar fontes sob autorização

Abrir exemplo detalhado →

06. Orçamento comercial

Fluxo: Catálogo → regras de preço → proposta

Tecnologias: n8n, CRM, APIs

Quando usar agente: Coletar requisitos incompletos, sem inventar preço

Abrir exemplo detalhado →

07. Pós-venda e satisfação

Fluxo: Formulário → classificação → encaminhamento

Tecnologias: ManyChat, Make, Zapier, n8n

Quando usar agente: Tratar exceções e propor respostas sujeitas a aprovação

Abrir exemplo detalhado →

08. Leads multiempresa

Fluxo: Canal → identificação tenant → distribuição

Tecnologias: CRM, PostgreSQL, n8n

Quando usar agente: Qualificar contexto mantendo isolamento entre empresas

Abrir exemplo detalhado →

09. Indicadores gerenciais

Fluxo: Fontes → agregação SQL → relatório

Tecnologias: SQL, Python, Power Automate

Quando usar agente: Interpretar anomalias e levantar hipóteses com evidências

10. Triagem de manutenção

Fluxo: Sensor ou chamado → regras de criticidade → fila

Tecnologias: Node-RED, NiFi, n8n

Quando usar agente: Investigar contexto e orientar humano, sem comandar equipamento indiscriminadamente

Tecnologias: Hermes, OpenClaw, dots, Grok Bot
