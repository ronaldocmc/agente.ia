Conceitos A–Z / Integração e automação

HTTP

Definição: Protocolo de comunicação entre clientes e servidores.

Como funciona: Use POST para enviar JSON; GET para leitura sem efeitos colaterais. O código de resposta indica o resultado.

Limites: HTTPS acrescenta proteção em trânsito; não substitui autorização.

Atividade: Veja o Lab 05.

Relacionado: Webhook · API · Idempotência
