13. Perguntas frequentes

É obrigatório começar com n8n? Não. Python é uma excelente alternativa para compreender os mecanismos fundamentais. O n8n é especialmente interessante quando integração e automação são requisitos centrais.

Preciso utilizar n8n e LangGraph simultaneamente? Não. A combinação é útil quando existe uma divisão clara entre automação de eventos e orquestração programável.

MCP substitui APIs? Não. Um servidor MCP frequentemente disponibiliza ferramentas que internamente utilizam APIs tradicionais.

Skill é apenas um prompt? Não necessariamente. Pode envolver procedimentos, scripts, referências e validações.

Todo chatbot é um agente? Não. Uma interface conversacional isolada não comprova autonomia ou capacidade de ação.

Todo orquestrador é inteligente? Não. Existem orquestradores inteiramente determinísticos.

Todo sistema multiagente é superior a um agente único? Não. É necessário avaliar resultados, custos e complexidade.

Um modelo pode fazer orquestração? Sim, quando integrado a um ambiente que permite selecionar ferramentas, delegar tarefas e coordenar agentes.

Preciso de um banco vetorial para implementar memória? Não. Estado e memória podem ser implementados em bancos relacionais, arquivos e outras estruturas.

Quando utilizar OpenClaw ou Hermes? Quando for interessante experimentar agentes com recursos de execução, sessões, ferramentas e canais integrados, respeitando isolamento e permissões.

Posso copiar uma implementação do GitHub e utilizá-la em produção? Não sem verificar requisitos, licença, segurança, manutenção, testes e condições operacionais.
