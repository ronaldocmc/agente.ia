5. Ecossistema de tecnologias: quais ferramentas fazem o quê?

Qual tecnologia escolher? Veja o mapa interativo de decisão, com filtros, comparação lado a lado e exemplos de aplicações.

As tecnologias precisam ser classificadas por sua função predominante.

Categoria Tecnologias Função principal
Plataformas prontas ChatGPT, Gemini, Claude Interação e execução de tarefas em ambientes disponibilizados pelos fornecedores
Modelos GPT, Gemini, Claude, Llama, modelos locais Interpretação, geração e análise
SDKs programáveis OpenAI Agents SDK, Google ADK, Claude Agent SDK, PydanticAI Desenvolvimento de agentes por código
Frameworks de orquestração LangGraph, CrewAI Coordenação, estados e múltiplos agentes
Automação visual n8n Integração e automação de processos
Construção visual Langflow; Flowise como referência histórica Experimentação de fluxos de IA
Runtimes agênticos OpenClaw, Hermes Agent Execução de agentes com sessões e ferramentas
Protocolos MCP, APIs, webhooks Interoperabilidade
Conhecimento RAG, embeddings, pgvector, Qdrant Recuperação de informações
Infraestrutura FastAPI, PostgreSQL, Docker Operação e persistência

5.1 ChatGPT, Gemini e Claude #

Esses ecossistemas já oferecem recursos agênticos, mas devemos distinguir seus produtos de interação dos SDKs usados por desenvolvedores.

Um assistente configurado dentro do ChatGPT, Gemini ou Claude pode ser suficiente para atividades pessoais e determinadas tarefas institucionais.

Contudo, desenvolver um sistema independente exige controle sobre backend, autenticação, armazenamento, ferramentas, permissões e implantação.

A existência de orquestração nativa nessas plataformas não significa que todas ofereçam os mesmos controles ou interfaces de programação.

5.2 n8n #

O n8n é particularmente útil quando a necessidade central envolve integração de sistemas, eventos, agendamentos e automações.

Pode utilizar modelos de linguagem, ferramentas, memória e componentes agênticos.

É uma boa escolha para conectar banco de dados, APIs, serviços de comunicação e mecanismos de execução.

5.3 OpenAI Agents SDK #

É uma alternativa para desenvolver agentes programáveis com Python ou TypeScript.

Permite definir agentes, ferramentas, execução, delegação e padrões multiagentes.

É interessante para iniciar o desenvolvimento programático, especialmente quando queremos integrar agentes a sistemas próprios.

5.4 Google ADK #

Oferece recursos para desenvolver agentes, utilizar ferramentas, estruturar workflows e trabalhar com especialistas.

Pode utilizar diferentes modelos e arquiteturas, incluindo execução sequencial, paralela e formas de coordenação dinâmica.

5.5 Claude Agent SDK #

Oferece mecanismos para desenvolver agentes com ferramentas e recursos de execução.

É especialmente interessante para tarefas envolvendo arquivos, programação e operações em ambientes controlados.

Deve ser utilizado com atenção às permissões concedidas.

5.6 LangGraph #

É apropriado para aplicações que exigem representação explícita de estado, transições, ciclos, interrupções e retomada de processos.

Um processo com várias etapas, falhas recuperáveis e aprovação humana pode se beneficiar dessa abordagem.

5.7 CrewAI #

É voltado à construção de aplicações com agentes especializados e fluxos de execução.

Possui conceitos como Crews, para equipes, e Flows, para controle de processos.

É útil para estudar coordenação multiagente, mas deve ser comparado com alternativas de agente único.

5.8 PydanticAI #

É interessante para sistemas Python que precisam de entradas, dependências e saídas estruturadas.

Ajuda na validação de contratos, mas a validação estrutural não substitui verificações semânticas ou de autorização.

5.9 OpenClaw e Hermes Agent #

Essas tecnologias disponibilizam ambientes de execução de agentes com ferramentas, sessões, memória e integrações.

São interessantes para experimentação com assistentes pessoais e automação agêntica.

Entretanto, o acesso a arquivos, navegador, shell, contas e outros recursos exige atenção especial à segurança.

5.10 Flowise e Langflow #

São ou foram ferramentas relevantes para a construção visual de fluxos de IA.

O Flowise original foi arquivado em 2026, com encerramento do suporte oficial anunciado para agosto daquele ano. Por isso, deve ser tratado como referência didática histórica ou avaliado cuidadosamente antes de uma nova implantação.

O Langflow continua como alternativa para experimentação visual, dependendo das versões e condições de implantação disponíveis.

5.11 Matriz de seleção #

Necessidade Primeiro candidato
Automatizar processos e conectar sistemas n8n
Criar o primeiro agente Python OpenAI Agents SDK ou Google ADK
Controlar estados e fluxos complexos LangGraph

Trabalhar com saídas fortemente tipadas PydanticAI
Criar assistentes com muitas ferramentas OpenClaw ou Hermes
Consultar documentos institucionais RAG

Reutilizar procedimentos especializados Agent Skills
