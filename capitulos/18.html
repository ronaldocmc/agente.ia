18. Novos frameworks, serviços gerenciados e agentes de programação

18.1 Microsoft Agent Framework #

O Microsoft Agent Framework oferece desenvolvimento de agentes e orquestração em Python e .NET, com padrões sequenciais, paralelos e de handoff, integração com ferramentas e suporte a diferentes provedores de modelos. É relevante para aplicações corporativas e para a comparação com Google ADK, OpenAI Agents SDK, CrewAI e LangGraph. A documentação oficial e o histórico de lançamentos devem ser consultados para fixar versões de dependências; houve publicação da linha Python 1.24.0 em 30 de outubro de 2026.

Estudo comparativo: desenvolver a mesma triagem de CRM com três ferramentas, utilizando o mesmo modelo, dataset, funções externas e regras de aprovação. Medir corretude, tempo, custo, reprodutibilidade e complexidade do código.

18.2 Strands Agents #

Strands Agents é uma abordagem programável de agentes, com SDKs e recursos de ferramentas, sessões, execução, memória e interoperabilidade com MCP. A ideia é fornecer um ciclo de execução de agentes personalizável, sem obrigatoriamente depender de um plano de controle hospedado. É uma alternativa a ser avaliada para Python/TypeScript e modelos locais ou remotos.

18.3 Amazon Bedrock AgentCore #

Amazon Bedrock AgentCore é uma plataforma de infraestrutura para agentes, envolvendo recursos de runtime, identidade, políticas, gateway, observabilidade e ferramentas de execução. A AWS anunciou disponibilidade na região São Paulo em maio de 2026, o que pode ser relevante para requisitos de latência e residência de dados. AgentCore não é sinônimo de SDK: pode hospedar agentes desenvolvidos com diferentes frameworks. Não dispensa políticas organizacionais, controle de custos e revisão de segurança.

18.4 Agentes de programação e protocolo ACP #

Agentes de programação são um subtipo orientado à leitura, modificação e verificação de código. Alguns atuam em IDEs, repositórios e ambientes computacionais isolados. O Agent Client Protocol (ACP) busca padronizar a comunicação entre editores e agentes de programação. Não se confunde com MCP: ACP conecta editor e agente; MCP pode conectar o agente a ferramentas; A2A conecta sistemas agênticos independentes.

18.5 OpenClaw e Hermes como runtimes #

OpenClaw e Hermes continuam relevantes como ambientes integrados que já oferecem sessões, ferramentas, canais e mecanismos de execução. São opções de experimentação, especialmente para assistentes e fluxos com várias ferramentas, mas requerem avaliação cuidadosa de permissões sobre navegador, shell, dados e canais externos. Não é prudente comparar esses runtimes diretamente com um protocolo como MCP ou com o modelo de linguagem em si: ocupam funções distintas no ecossistema.
