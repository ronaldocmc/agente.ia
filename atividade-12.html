ATIVIDADE 12 · AVANÇADO

Escritório Virtual de gestores — protótipo integrador

Integrar automação, agente e governança sem colocar um agente no comando das decisões institucionais

Tecnologia: n8n + FastAPI + PostgreSQL + agenteModalidade: Projeto integradorDados: sintéticos

Por que usar esta tecnologia?

Integrar automação, agente e governança sem colocar um agente no comando das decisões institucionais O aluno deverá comparar essa escolha com uma alternativa mais simples, explicando o custo adicional de complexidade.

Qual LLM e por quê?

LLM local ou via API conforme testes de qualidade e política institucional; a aplicação conserva controles determinísticos.

Fluxograma da execução

Painel / formulário→FastAPI + autorização→n8n / agente→PostgreSQL→Aprovação humana

Roteiro de implementação

  1. Defina três perfis fictícios: direção, área acadêmica e secretaria; não use dados reais.
  2. Modele solicitações, anexos, eventos, aprovações e trilha de auditoria no PostgreSQL ou armazenamento de teste.
  3. Crie API FastAPI com endpoints de consulta, registro e aprovação autenticada simulada.
  4. Crie workflow n8n para receber solicitações sintéticas e acionar validações.
  5. Adicione um agente para classificar pedidos e redigir minutas; o agente não aprova nem envia.
  6. Implemente painel simplificado com fila de aprovação e histórico.
  7. Execute cenários de permissão indevida, fonte desconhecida, falha de integração e pedido urgente.
  8. Compare a versão com agente com uma automação determinística.

Testes mínimos e resultado esperado

  • Somente ator autorizado aprova.
  • Toda ação gera registro auditável.
  • Agente não acessa dados fora do escopo.

O que entregar

  • Repositório + README
  • Diagramas
  • Testes + relatório
  • Vídeo demonstrativo

Como avançar

Explorar sessões persistentes com OpenClaw ou estado com LangGraph somente após justificar.

Critérios de avaliação

Funcionamento e evidências (30%), explicação da arquitetura e tecnologia (20%), testes e métricas (20%), segurança e permissões (15%), documentação e reprodutibilidade (15%).

Atenção ao docente: estes roteiros são propostas de atividades, não certificações de execução no ambiente dos alunos. Registre versão de ferramenta, modelo, sistema operacional, hardware e evidências de sucesso ou falha. Não fornecer dados pessoais ou credenciais reais.
