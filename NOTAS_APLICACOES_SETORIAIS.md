# Formação individual — aplicações setoriais

Foram acrescentadas 50 páginas (cinco desafios por tecnologia) e dois índices orientadores. Os cenários são inspirados em necessidades empresariais, mas dados e organizações são simulados. Isso não comprova implantação nas empresas nem teste de todos os runtimes.

Menu: Formação individual → Aplicações reais simuladas (50).

Cada aluno pode concluir a atividade principal, uma aplicação, outra aplicação e migrar para uma nova tecnologia.

Arquivos: `aplicacoes-setoriais.html`, `guia-de-escolha-aplicacoes.html`, `aplicacao-XX-YY.html`.

Total de links de navegação atualizados: 365.
