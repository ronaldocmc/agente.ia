Laboratório de segurança e governança de agentes

Aprenda a separar a intenção produzida pelo modelo de uma ação autorizada. O exercício usa um simulador determinístico de um assistente que consulta cursos; não modifica dados reais nem permite que o modelo execute ações administrativas.

Mensagem do usuário / resultado de ferramenta não confiável
↓
Validação de dados, identidade, função e ação
↓
Política de autorização (código determinístico)
↓
Ferramenta simulada ou bloqueio + log de auditoria

Implementação passo a passo

  1. Abra laboratorios/fases-aprendizagem.
  2. Execute python testes_formacao.py para testar a política e o tratamento das entradas.
  3. Execute python seguranca_agente.py para ver cinco cenários e seus registros.
  4. Altere o papel do usuário entre visitante e operador e compare quais ações são permitidas.
  5. Simule texto de terceiros contendo instruções para ignorar políticas. A saída deve permanecer bloqueada porque autorização não é decidida pelo texto do modelo.
  6. Registre o evento, a política acionada e a justificativa. Identifique o que mudaria caso a ferramenta acessasse uma API real.

Cinco testes mínimos

CenárioResultado esperado
Consulta autorizadaDados fictícios retornados
Ação administrativa sem permissãoBloqueio
Solicitação sem parâmetrosPedido de informação adicional
Instrução maliciosa em conteúdo externoIgnorar como comando e registrar
Ferramenta desconhecidaBloqueio e registro

Aprofundamento

Reimplemente o mesmo controle em n8n, Agents SDK, LangGraph, Hermes ou OpenClaw. Mantenha a autorização fora do prompt, com credenciais de privilégio mínimo, aprovação humana para efeitos externos e logs sem dados sensíveis.
