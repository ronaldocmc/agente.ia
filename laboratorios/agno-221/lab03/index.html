Tutorial Agno / Laboratório 03
Agno · Laboratório 03

Tools, skills e saída estruturada

1. Objetivo e arquitetura

Encapsular capacidades Python e validar a resposta por esquema.

Utilize exclusivamente dados sintéticos; nenhuma integração institucional foi configurada.

2. Preparar o ambiente

Abra um terminal nesta pasta. Python 3.12 recomendado. Crie um ambiente virtual separado e ative-o.

python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip freeze > ambiente-validado.txt

Defina OPENAI_API_KEY no ambiente, sem gravá-la no código. Para modelo local consulte o Lab02. O arquivo .env.example é ilustrativo; o script lê variáveis do ambiente, não carrega .env automaticamente.

3. Arquivos do laboratório

.env.example · SKILL.md · app.py · catalogo.csv · comum.py · norma.txt · requirements.txt · testar.py

4. Executar e experimentar

python testar.py
python app.py

Leia SKILL.md: neste laboratório é uma instrução carregada explicitamente, não um carregador nativo de skills. Valide a estrutura e confronte os valores com o CSV.

Examine o código:

from agno.agent import Agent
from pydantic import BaseModel
from comum import modelo, consultar_curso, BASE
class Resultado(BaseModel):
    codigo: str
    encontrado: bool
    nome: str | None = None
agente=Agent(model=modelo(), tools=[consultar_curso], instructions=(BASE/"SKILL.md").read_text(encoding="utf-8"), output_schema=Resultado)
if __name__ == "__main__":
    r=agente.run(input("Código: "))
    print(Resultado.model_validate(r.content).model_dump_json())

5. Validar e avaliar

C002 encontrado; C999 encontrado=false; resposta sem conformidade deve falhar na validação.

Registre entrada, resultado observado, resultado esperado, tempo, versão do SDK e eventual falha. Os testes locais da ferramenta são independentes do SDK; o experimento Agno exige instalação e configuração.
