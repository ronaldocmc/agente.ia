# Integração de referência — Openclaw

Conteúdo demonstrativo com skill no formato Markdown e script isolado; não há alegação de instalação ou execução do runtime. Teste o script local primeiro:

`python tools/consulta_certificado.py ana@exemplo.test ana@exemplo.test`
