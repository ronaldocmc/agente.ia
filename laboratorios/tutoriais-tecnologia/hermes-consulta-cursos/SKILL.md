# Procedimento
Leia unicamente o catálogo anexado a esta skill ou disponibilizado no diretório isolado pelo docente. Procure ID ou nome exato. Cite a fonte. Se faltar o dado, explique. Não altere inscrições, não acesse contas, não envie mensagens e não execute comandos. Este arquivo descreve instruções; configure a política de ferramentas e o isolamento separadamente.
