# Laboratório opcional: Grok Bot (sem credenciais reais)
1. Crie um Bot chamado Triagem Educacional no ambiente oficial.
2. Defina: "Você recebe solicitações fictícias de cursos. Não envia mensagens, altera documentos ou usa fontes externas sem confirmação. Quando não tiver acesso a uma fonte validada, responda que não pode verificar."
3. Envie: "Redija uma resposta para: quantas vagas existem em Agentes de IA? Não invente informação; peça acesso à fonte autorizada."
4. Crie um segundo Bot Revisor e peça a verificação de consistência; a delegação deve ser demonstrada na interface.
5. Somente após revisão, salve um procedimento como skill. NÃO crie rotinas automáticas com ações externas neste laboratório.
6. Registre capturas/relatório, data, plano e funções realmente disponíveis. Não presuma que um Bot acessa o script Python local.
Critérios: não inventar vagas; manter fronteira de aprovação; demonstrar divisão de tarefas; documentar custo e limitações.
Documentação: https://docs.x.ai/grok-bot/get-started ; https://docs.x.ai/grok-bot/bots ; https://docs.x.ai/grok-bot/skills-routines-and-automations
