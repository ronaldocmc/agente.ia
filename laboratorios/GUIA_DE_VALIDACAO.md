# Checklist para comprovar a execução de cada laboratório

- [ ] Versão do framework, modelo e sistema operacional documentados
- [ ] Arquivos e comandos reais executados sem exceções
- [ ] Logs da chamada da ferramenta em cenário válido
- [ ] Curso inexistente sem alucinação
- [ ] Tentativa de alteração não autorizada bloqueada por código/permissão
- [ ] Distinção explícita entre workflow determinístico e decisão agêntica
- [ ] Custo, latência e dependências observados
- [ ] Escopo mínimo de permissão e dados exclusivamente sintéticos
- [ ] Comparação com baseline Python

A presença do roteiro não comprova a execução do runtime ou provedor.
