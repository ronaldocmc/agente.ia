# Escritório Virtual Alfa — Laboratório 13
Baixe demandas.json e validar.py na mesma pasta. Execute `python3 validar.py` para gerar referencia.json. O arquivo de referência deve ficar com o avaliador, não com a Triagem durante o teste independente.
Configure os quatro agentes usando instrucoes.md (cada seção em seu AGENTS.md). A skill opcional está em skills/triagem/SKILL.md. Use somente dados sintéticos.
Entregas: triagem.json (lista com id e destino), parecer.md (propostas por demanda), revisao.md (divergências e decisão recomendada). O humano registra a decisão na issue. 
Registre versão, adaptador, IDs de issues/runs, resultado observado dos testes, custo reportado e limitações.
