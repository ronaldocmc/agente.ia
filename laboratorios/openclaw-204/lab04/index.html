Lab 04 — Integração com Telegram

Lab 04 — Telegram integration

Objetivos de aprendizagem

Learning objectives

Configurar bot privado e verificar admissão de mensagens.

Configure a private bot and verify message admission.

Pré-requisitos

Prerequisites

Lab 01, duas contas de teste consentidas, BotFather.

Lab 01, two consenting test accounts and BotFather.

Arquitetura da atividade

Lab architecture

Arquivos para experimentação

Experiment files

  • Configuração parcial / Partial configuration config-exemplo.json
  • Matriz de testes / Test matrix testes.csv

Implementação passo a passo

Step-by-step implementation

1. Criar bot

1. Create bot

No Telegram oficial, abra @BotFather, use /newbot e guarde o token privadamente. Não compartilhe token ou capturas que o revelem.

In Telegram, use @BotFather /newbot and keep the token private. Never share token screenshots.

2. Configurar canal

2. Configure channel

Execute o assistente e selecione Telegram; informe token de forma privada. Mescle a configuração de exemplo, substituindo o ID pelo numérico real da conta autorizada. Não sobrescreva o arquivo inteiro. Desative grupos.

Run channel setup, choose Telegram and enter token privately. Merge the example config with the authorized numeric ID; do not overwrite your config. Disable groups.

openclaw channels add
openclaw gateway status

3. Testar acesso

3. Test access

Envie LAB04 OK pela conta autorizada; pela segunda conta envie a mesma mensagem. Não aprove o segundo remetente. Use agente sem ferramentas sensíveis.

Send LAB04 OK from the allowed account, then from the second account. Do not approve the second sender. Use an agent without sensitive tools.

4. Encerrar

4. Clean up

Preencha testes.csv e confira logs sem segredos. Desative canal de laboratório e revogue token se não for mais usado.

Fill tests.csv, inspect redacted logs, disable the lab channel and revoke an unused token.

Resultados esperados e diagnóstico

Expected results and troubleshooting

Somente conta autorizada deve iniciar turno; grupos bloqueados. Se ambos respondem, interrompa e revise allowFrom e política efetiva.

Only authorized account should trigger a turn; groups blocked. If both get agent replies, stop and check effective policy.

Avaliação e entregáveis

Assessment and deliverables

Entregue versão, modelo, diagrama, configuração redigida, prompts, evidências observadas, testes negativos e discussão das diferenças. Não inclua tokens nem dados pessoais.

Submit version, model, diagram, redacted configuration, prompts, observed evidence, negative tests and a discussion of differences. Never include secrets or personal data.
