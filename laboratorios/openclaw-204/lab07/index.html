Lab 07 — Observar.IA — Curadoria pelo WhatsApp

Lab 07 — Observar.IA — WhatsApp curation

Objetivos e escopoObjectives and scope1. Preparar o backend1. Backend setup2. Instalar a ponte confiável2. Install trusted bridge3. Curadoria pelo WhatsApp3. WhatsApp curation4. Visualizar o resultado4. View the result5. Testes e avaliação5. Tests and assessment

Objetivos e escopo

Labs 01–06. Implementar F01 encaminhar fonte, F02 solicitar publicação, F03 registrar curadoria e publicação local. Use três números consentidos e um número dedicado ao Gateway. O laboratório tem duas fases: agentes com fontes sintéticas e integração via WhatsApp com decisões determinísticas.

Objectives and scope

Labs 01–06. Implement source submission, publication requests, curation and local publishing. Use three consenting participants and a dedicated Gateway number. Two phases: agents with synthetic sources and WhatsApp integration with deterministic decisions.

  • Fase A — Radar, Verificador e Curador / Offline agent exercise
  • Backend Python + SQLite
  • Testes / Tests
  • HOOK.md
  • Handler JavaScript
  • Instruções do agente / Agent instructions
  • Configuração WhatsApp / WhatsApp config

1. Preparar o backend

Em Linux/WSL, execute em um ambiente descartável, sob controle do operador. O backend usa biblioteca padrão Python, não requer FastAPI. Substitua os três números pelos reais autorizados. O token deve ficar fora de prompts, arquivos de workspace e logs. Use usuários de sistema/isolamento distintos para impedir que ferramentas do agente leiam segredos, banco ou API de mutação. Não exponha a porta 8765 à rede.

1. Backend setup

On Linux/WSL use an operator-controlled disposable environment. Standard Python only. Replace three numbers with authorized real numbers. Keep token outside prompts, workspaces and logs. Enforce separate OS identities or isolation so agent tools cannot read secrets, DB or mutation API. Do not expose port 8765.

export OBS_TOKEN="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
export OBS_ROLES='{"+5518000000001":"colaborador","+5518000000002":"curador","+5518000000003":"editor"}'
python3 -m unittest -v test_backend
python3 backend.py

2. Instalar a ponte confiável

Em outro terminal do operador, disponibilize o mesmo OBS_TOKEN ao processo Gateway por um mecanismo seguro. Copie o diretório hook/observar-wa para ~/.openclaw/hooks/ sem sobrescrever instalação existente. Habilite e reinicie o Gateway. Configure o WhatsApp com os três números, DM allowlist, grupos desativados e selfChatMode false. Use AGENTS-bridge.md e negue ferramentas de execução, acesso a segredos, arquivos e rede no agente. O hook recebe a identidade do canal; nunca aceite um número informado no texto. Se a versão não fornecer senderE164 ou messageId, o hook não age. Confira o evento com dados sintéticos e não registre conteúdo ou números reais.

2. Install trusted bridge

In a separate operator terminal, securely provide the same OBS_TOKEN to the Gateway process. Copy hook/observar-wa into ~/.openclaw/hooks/ without overwriting an existing hook. Enable and restart Gateway. Configure WhatsApp with three allowed numbers, no groups, selfChatMode false. Use AGENTS-bridge.md and deny agent execution, network, filesystem and secret access. The hook uses channel identity, never user-supplied sender text. It fails closed when senderE164 or messageId is absent. Validate the event with synthetic data; do not log real content or numbers.

mkdir -p ~/.openclaw/hooks
cp -r hook/observar-wa ~/.openclaw/hooks/
openclaw hooks info observar-wa
openclaw hooks enable observar-wa
openclaw hooks check
openclaw gateway status

3. Curadoria pelo WhatsApp

Envie os comandos abaixo como mensagens individuais, usando o telefone do papel indicado. O curador lê a fonte manualmente e pode preparar a síntese com os agentes da fase A; o backend não acessa o site automaticamente. O primeiro registro de um banco novo será OBS-001. Consulte antes de aprovar. O hook envia confirmação separada; o agente conversacional não é autoridade sobre o estado. Encaminhe o ID ao próximo participante manualmente.

3. WhatsApp curation

Send each command as a separate message from the phone of the indicated role. The curator reads the source manually and may prepare the draft using phase A agents; the backend does not fetch URLs. First record in a fresh database is OBS-001. Inspect before approving. Hook sends a separate confirmation; conversational agent is not the source of truth. Forward the ID manually to the next participant.

4. Visualizar o resultado

Abra boletim local. Somente observações publicadas com aprovação da versão correspondente aparecem. Não há postagem externa nem painel web administrativo. Consulte o SQLite pelo operador para auditar registros e decisões. Não compartilhe dados pessoais.

4. View the result

Open the local bulletin. Only published observations with matching approved versions appear. No external posting or administrative web dashboard. Operator can inspect SQLite for audit. Do not share personal data.

5. Testes e avaliação

Teste colaborador aprovando (negado), editor publicando antes da aprovação (negado), revisão invalidando aprovação, versão antiga (negada), mensagem repetida e remetente desconhecido. O teste Python cobre o fluxo de estados sem WhatsApp. Execute também os testes reais de canal. Rubrica: integração 3, curadoria e papéis 3, evidências 2, reflexão 2. Desafio: atribuição individual de curadores, encaminhamento automático, painel Web e coleta real supervisionada.

5. Tests and assessment

Test contributor approval (denied), premature publication (denied), revision invalidating approval, old version (denied), repeated message and unknown sender. Python tests the state flow without WhatsApp. Run live channel tests separately. Rubric: integration 3, curation and roles 3, evidence 2, reflection 2. Extension: individual curator assignment, automatic routing, web dashboard and supervised live collection.

Limites: um curador compartilhado por papel, encaminhamento humano, fontes sem coleta automática. O hook e a integração real com WhatsApp precisam de validação na versão instalada. Não é uma implementação institucional completa.

Limits: shared curator role, manual handoffs, no automatic crawling. Live hook and WhatsApp integration must be verified on the installed version. Not a complete institutional implementation.
