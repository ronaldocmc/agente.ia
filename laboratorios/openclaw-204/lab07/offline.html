Objetivos de aprendizagem

Learning objectives

Integrar três agentes especializados com aprovação humana e boletim local.

Integrate three specialized agents with human approval and a local bulletin.

Pré-requisitos

Prerequisites

Labs 01–03, Python 3, três workspaces isolados e dados exclusivamente fictícios.

Labs 01–03, Python 3, three isolated workspaces and synthetic data only.

Arquitetura da atividade

Lab architecture

Arquivos para experimentação

Experiment files

  • Fontes simuladas / Simulated sources fontes.json
  • Agente Radar radar/AGENTS.md
  • Agente Verificador verificador/AGENTS.md
  • Agente Curador curador/AGENTS.md
  • Rascunho / Draft rascunho-exemplo.json
  • Validação e publicação local / Local validation and publishing fluxo.py

Implementação passo a passo

Step-by-step implementation

1. Preparar agentes

1. Prepare agents

No terminal, crie três agentes usando o assistente. Copie o AGENTS.md de cada papel para seu workspace depois de revisar instruções existentes; copie fontes.json para os três. Não conecte canais públicos.

Create three agents with the wizard. Copy each role AGENTS.md after reviewing existing instructions; copy fontes.json to all three. Do not connect public channels.

openclaw agents add radar
openclaw agents add verificador
openclaw agents add curador

2. Coletar e verificar

2. Collect and check

A coleta é simulada com três registros locais. Solicite ao Radar os candidatos e duplicatas; encaminhe a resposta manualmente ao Verificador junto com fontes. Registre pareceres.

Collection is simulated using three local records. Ask Radar for candidates and duplicates; manually forward output to Verifier with sources. Save findings.

openclaw agent --agent radar --message "Leia fontes.json e liste candidatos e duplicatas."
openclaw agent --agent verificador --message "Revise fontes.json e identifique duplicatas."

3. Curar

3. Curate

Envie ao Curador os pareceres reais por chat, solicite JSON no formato do exemplo. Salve a resposta revisada como rascunho.json na pasta lab07.

Send actual findings to Curator in chat, request JSON matching the example. Save reviewed response as rascunho.json in lab07.

4. Validar e aprovar

4. Validate and approve

No terminal do operador, fora do alcance de escrita dos agentes, execute a validação e confira títulos, fontes e resumos antes de aprovar. O hash vincula aprovação ao conteúdo.

In operator terminal outside agent write access, validate and inspect titles, sources and summaries before approval. Hash binds approval to content.

python fluxo.py validar --rascunho rascunho.json
python fluxo.py aprovar --rascunho rascunho.json --revisor DOCENTE
python fluxo.py publicar --rascunho rascunho.json

5. Testes negativos e evolução

5. Negative tests and extension

Tente publicar antes de aprovar; altere o rascunho após aprovação e repita. Teste ID inválido e URL duplicada. Use rascunho-exemplo.json para ensaio sem modelo. Como extensão, configure cron para coleta de rascunhos, nunca aprovação ou publicação automática.

Try publishing before approval; change draft after approval and retry. Test unknown ID and duplicate URL. Use example draft for offline trial. As extension, configure cron for draft collection, never automatic approval or publication.

Resultados esperados e diagnóstico

Expected results and troubleshooting

Dois itens fictícios únicos; boletim HTML local somente após aprovação correspondente. O protótipo usa passagem manual entre agentes, não uma orquestração autônoma nem coleta real da web.

Two unique synthetic items; local HTML only after matching approval. Manual handoffs, not autonomous orchestration or live web collection.

Avaliação e entregáveis

Assessment and deliverables

Entregue versão, modelo, diagrama, configuração redigida, prompts, evidências observadas, testes negativos e discussão das diferenças. Não inclua tokens nem dados pessoais.

Submit version, model, diagram, redacted configuration, prompts, observed evidence, negative tests and a discussion of differences. Never include secrets or personal data.
