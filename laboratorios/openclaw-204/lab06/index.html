Lab 06 — Assistente pessoal pelo WhatsApp

Lab 06 — Personal assistant via WhatsApp

Objetivos e pré-requisitosObjectives and prerequisites1. Preparar o ambiente1. Prepare environment2. Configurar e parear2. Configure and pair3. Primeiro diálogo3. First conversation4. Avaliação e diagnóstico4. Assessment and troubleshooting

Objetivos e pré-requisitos

Configurar um assistente pessoal pelo WhatsApp, testar acesso e aprender o Gateway. Labs 01 e 03; número dedicado, dois participantes consentidos, modelo configurado.

Objectives and prerequisites

Configure a personal assistant over WhatsApp, test access and learn the Gateway. Labs 01 and 03; dedicated number, consenting participants and configured model.

  • Configuração / Configuration
  • Instruções / Instructions

1. Preparar o ambiente

Use uma instalação descartável. Faça backup da configuração. Crie um agente de laboratório pelo assistente openclaw agents add assistente-wa; copie AGENTS.md ao workspace correspondente. Configure o roteamento do canal para este agente na UI. Desabilite ferramentas de execução, arquivos, mensagens a terceiros e automação; confira a política efetiva.

1. Prepare environment

Use a disposable installation and back up configuration. Create a lab agent with openclaw agents add assistente-wa, copy AGENTS.md into its workspace, and route the channel to it via UI. Disable execution, files, third-party messaging and automation; check effective policy.

2. Configurar e parear

Mescle o JSON de exemplo à configuração existente, substituindo números fictícios por números consentidos. Use aparelho dedicado; revise pareamentos anteriores, desative grupos. Escaneie QR em Aparelhos conectados. Se o gateway não estiver iniciado, inicie com openclaw gateway. Não compartilhe QR ou credenciais.

2. Configure and pair

Merge the sample JSON into existing configuration with consenting real numbers. Use a dedicated device, review previous pairing grants and disable groups. Scan the QR in Linked devices. Start the gateway with openclaw gateway if stopped. Never share QR or credentials.

openclaw plugins install @openclaw/whatsapp
openclaw channels login --channel whatsapp
openclaw gateway status
openclaw channels status --probe

3. Primeiro diálogo

Envie: “Tenho aula às 8h, reunião às 10h e revisão às 14h. Organize minha agenda fictícia.” Confira se o retorno contém três horários e não afirma ter alterado calendário. Repita com um telefone não autorizado: não deve receber resposta do agente.

3. First conversation

Send: “Class at 8, meeting at 10 and review at 14. Organize my fictional agenda.” Verify all three times and no calendar-change claim. Repeat from a non-authorized phone; no agent response should arrive.

4. Avaliação e diagnóstico

Entregue versão, configuração sem segredos, evidência do pareamento sem QR, respostas autorizadas e teste negativo. Rubrica: configuração 3, diálogo 3, controle de acesso 3, reflexão 1. Se desconectado, verifique status e refaça pareamento somente se necessário. Revogue o vínculo ao terminar.

4. Assessment and troubleshooting

Submit version, redacted config, pairing evidence without QR, authorized replies and negative test. Rubric: setup 3, dialogue 3, access control 3, reflection 1. Check status and re-pair only if necessary; unlink when finished.
