Optional Brazilian model experiment. See the Lumi Wiki profile and official model card. Use a compatible Linux GPU environment with enough memory; BF16 weights occupy about 8 GB before runtime overhead. A compatible vLLM installation is required. Keep thinking disabled.

3. Pontuar e medir

3. Score and measure

Cada arquivo contém nove chamadas por padrão. Compare resposta textual com gabarito, registre acerto 0/1. Preencha tokens e custo quando disponíveis; falhas não são acertos.

Each file has nine calls by default. Compare text with ground truth, record 0/1. Fill tokens and cost when available; failures are not successes.

4. Interpretar

4. Interpret

Calcule acertos/9, mediana de latência das execuções bem-sucedidas e custo total observado. API: tokens × preço por milhão / 1.000.000, separando entrada e saída. Local: custo energético/infraestrutura, se medido; não declarar custo total zero.

Compute successes/9, median successful latency and observed total cost. API: tokens × price per million / 1,000,000 by input/output. Local: energy/infrastructure if measured; do not assume zero total cost.
