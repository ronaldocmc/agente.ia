Integração e configuraçãoIntegration and configuration

Em uma VM/conta descartável, faça backup da configuração e mescle o fragmento em ~/.openclaw/openclaw.json. Instale e configure o backend de sandbox documentado, com Docker ativo. Reinicie o Gateway conforme o modo de instalação. Não substitua chaves de provedor nem exponha o Gateway.In a disposable VM/account, back up and merge into ~/.openclaw/openclaw.json. Configure the documented sandbox backend, with Docker running. Restart Gateway using its installation method. Do not replace provider credentials or expose Gateway.

{
  "agents": {"defaults": {"sandbox": {"mode": "all", "scope": "agent", "workspaceAccess": "ro"}}},
  "tools": {"deny": ["exec", "write", "edit", "apply_patch"], "elevated": {"enabled": false}},
  "gateway": {"bind": "loopback"}
}
openclaw --version
openclaw gateway status
openclaw security audit
openclaw security audit --deep

A política de ferramentas impede chamadas; sandbox determina onde elas rodam; modo elevado desativado impede a via elevada. O Gateway e plugins não ficam necessariamente dentro do sandbox. Use conta dedicada e permissões do SO.Tool policy restricts calls; sandbox controls execution location; disabled elevation removes elevated execution. Gateway and plugins are not necessarily sandboxed. Use a dedicated OS account and permissions.

Copie SKILL.md para uma pasta observar-resumo dentro do diretório de skills do workspace ou perfil de teste; confira a descoberta na interface. Experimente antes/depois com a mesma notícia sintética; compare precisão, consistência e evidências.Copy SKILL.md into an observar-resumo folder in the test workspace or profile skills directory; check discovery. Compare before/after on the same synthetic news item.

Testes e avaliaçãoTests and assessment

Resultado esperados: todas as asserções passam; registre os bloqueios e aprovações observados. A fase nativa não foi executada na produção deste material. A simulação não autentica usuários reais; identidades são fornecidas pelo test harness.Expected: all assertions pass; record observed denials and approvals. Native phase has not been executed in preparing this material. Simulation does not authenticate real users; identities come from the test harness.

Entregue evidencias.md preenchido, configuração sanitizada, saída dos testes e explicação das limitações. Rubrica: configuração 25%, evidências 35%, análise de falhas 30%, reprodução 10%.Submit completed evidence template, redacted config, test output and limitations. Rubric: configuration 25%, evidence 35%, failure analysis 30%, reproducibility 10%.
