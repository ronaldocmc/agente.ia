# Enunciado padrão para todas as equipes

## Objetivo
Implementar e avaliar a solução descrita na atividade atribuída usando **a tecnologia indicada**, justificando cada componente.

## Identificação
- Grupo:
- Atividade:
- Versões de software / sistema operacional:
- Modelo e runtime de inferência (se houver):
- Hardware / limitações:

## Entrega obrigatória
1. Problema, requisitos e hipótese de uso de agentes.
2. Arquitetura com separação de interface, workflow, runtime de agente, modelo e dados.
3. Tutorial passo a passo **reproduzido pelo grupo**, com comandos e capturas de tela.
4. Repositório sem credenciais, com README e dados sintéticos.
5. Conjunto de pelo menos cinco casos de teste: normal, dado ausente, ambíguo, proibido e falha de integração.
6. Logs e resultados (marcar claramente erros e tentativas não concluídas).
7. Comparação com uma solução determinística ou agente único; justificar uso de framework/runtime.
8. Riscos: dados, prompt injection, permissões, validação humana, custo.
9. Vídeo demonstrativo curto ou apresentação ao vivo.

## Critérios
- 30% funcionamento demonstrado
- 20% arquitetura e justificativa tecnológica
- 20% testes e métricas
- 15% segurança, governança e aprovações
- 15% documentação e reprodutibilidade

## Restrições
Nunca usar credenciais institucionais, WhatsApp pessoal de terceiros, informações pessoais reais ou sistemas administrativos de produção. Falhas de instalação são resultados aceitáveis somente quando documentadas e acompanhadas de diagnóstico verificável.
