Objetivo / Objective

Modelos locais, servidores e APIs com evidência reproduzível e controle de permissões.

Local models, servers and APIs with reproducible evidence and permission controls.

Pré-requisitos / Prerequisites

Ambiente de laboratório isolado, dados sintéticos, Python 3 quando necessário e Hermes configurado (exceto Lab 01).

Isolated lab environment, synthetic data, Python 3 when needed and Hermes configured (except Lab 01).

Implementação passo a passo / Step by step

Passo / Step 1

Instale Ollama, baixe um modelo compatível e configure contexto de 64K se suportado.

Install Ollama, download a compatible model and configure 64K context if supported.

ollama pull qwen3:8b
ollama run qwen3:8b
hermes model

Passo / Step 2

Repita em servidor próprio protegido; teste Lumi via vLLM apenas se contexto e tool calling forem compatíveis.

Repeat on a protected self-hosted server; test Lumi via vLLM only if context and tool calling are compatible.

vllm serve ceia-research/lumi-4b --host 127.0.0.1 --port 8000

Passo / Step 3

Repita com API externa. Execute cada caso três vezes em sessões novas; preencha evidencias-inferencia.csv e registre tempo, qualidade, memória e custo.

Repeat with external API. Run each case three times in fresh sessions; record time, quality, memory and cost in the evidence CSV.

hermes model
hermes

Testes e avaliação / Tests and assessment

Tabela preenchida com três repetições por caso; incompatibilidades reportadas.

Three runs per case recorded; incompatibilities reported.

Entregue versão, comandos, logs sem segredos, resultados observados e discussão de falhas. Avaliação: correção 40%, evidência 30%, segurança 20%, clareza 10%.

Submit version, commands, sanitized logs, observed results and failure discussion. Rubric: correctness 40%, evidence 30%, security 20%, clarity 10%.

Se falhar, verifique permissões, caminho, versão, credencial e conectividade; não amplie privilégios para contornar o problema.

On failure, check permissions, paths, version, credentials and connectivity; do not broaden privileges as a workaround.
