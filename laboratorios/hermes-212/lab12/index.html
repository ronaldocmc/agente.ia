Integração e configuraçãoIntegration and configuration

Em perfil descartável, faça backup e mescle o YAML em ~/.hermes/config.yaml (ou arquivo do perfil). Docker deve estar ativo. Reabra CLI/Gateway após alteração. Não monte diretórios do host nem encaminhe credenciais.In a disposable profile, back up and merge YAML into ~/.hermes/config.yaml (or profile file). Docker must be running. Restart CLI/Gateway after editing. Do not mount host directories or forward secrets.

approvals:
  mode: manual
  timeout: 300
  cron_mode: deny
  single_query_mode: deny
  unattended_mode: deny
skills:
  write_approval: true
memory:
  write_approval: true
terminal:
  backend: docker
  docker_network: false
  docker_forward_env: []
  docker_mount_cwd_to_workspace: false
  container_persistent: false
  container_cpu: 1
  container_memory: 5120

hermes --version
hermes config edit
hermes config check
hermes doctor

Aprovações de comandos são baseadas em padrões, não em prova de segurança. A aprovação de memória/skills cobre as ferramentas próprias, não edições genéricas por terminal ou arquivo. Use Docker e proteja arquivos por permissões externas.Command approvals are pattern-based, not a proof of safety. Memory/skill approval covers dedicated tools, not generic file or terminal edits. Use Docker and external filesystem permissions.

Depois de iniciar o ambiente isolado, peça ao agente para ler um arquivo sintético permitido e tentar alterar um arquivo protegido de teste. Não use credenciais reais ou diretórios pessoais. Registre se a ferramenta foi negada, se o isolamento funcionou e se houve mudança de hash.After starting the isolated environment, ask the agent to read an allowed synthetic file and attempt to edit a protected test file. Never use real credentials or personal folders. Record denial, isolation and file hashes.

Testes e avaliaçãoTests and assessment

Resultado esperados: todas as asserções passam; registre os bloqueios e aprovações observados. A fase nativa não foi executada na produção deste material. A simulação não autentica usuários reais; identidades são fornecidas pelo test harness.Expected: all assertions pass; record observed denials and approvals. Native phase has not been executed in preparing this material. Simulation does not authenticate real users; identities come from the test harness.

Entregue evidencias.md preenchido, configuração sanitizada, saída dos testes e explicação das limitações. Rubrica: configuração 25%, evidências 35%, análise de falhas 30%, reprodução 10%.Submit completed evidence template, redacted config, test output and limitations. Rubric: configuration 25%, evidence 35%, failure analysis 30%, reproducibility 10%.
