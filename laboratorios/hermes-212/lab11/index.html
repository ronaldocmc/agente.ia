Aprovações de comandos são baseadas em padrões, não em prova de segurança. A aprovação de memória/skills cobre as ferramentas próprias, não edições genéricas por terminal ou arquivo. Use Docker e proteja arquivos por permissões externas.Command approvals are pattern-based, not a proof of safety. Memory/skill approval covers dedicated tools, not generic file or terminal edits. Use Docker and external filesystem permissions.

O backend local demonstra a política independentemente do LLM. Em uma integração real, o adaptador autentica o usuário e chama o serviço sob conta separada; o agente recebe somente operações autorizadas, não acesso ao banco nem ao arquivo de aprovação.The local backend demonstrates policy independently of the LLM. In real integration, a trusted adapter authenticates users and calls a separate-account service; do not give the agent access to database or approval files.

Atividade opcional — ponto de extensãoOptional activity — extension point

Examine o callback Python abaixo. Ele bloqueia três nomes de ferramentas como exemplo, não constitui uma política completa. Utilize o guia oficial de plugins para empacotar e habilitar em um perfil descartável. Confira os nomes das ferramentas na versão instalada.Examine the Python callback below. It blocks three tool names as an example, not a complete policy. Use the official plugin guide to package and enable it in a disposable profile. Check tool names in your installed version.

def gate(tool_name, **kwargs):
    if tool_name in {"terminal", "write_file", "patch"}:
        return {"action": "block", "message": "Lab policy"}

def register(ctx):
    ctx.register_hook("pre_tool_call", gate)

Teste a função localmente: gate("terminal") deve retornar action=block; gate("read_file") deve retornar None. Após configurar o plugin, solicite uma leitura e uma escrita em arquivos sintéticos e registre o resultado. Não retire os controles nativos para testar.Test locally: gate("terminal") should return action=block; gate("read_file") should return None. Once configured, request a read and write on synthetic files and record the outcome. Do not remove native controls for testing.
