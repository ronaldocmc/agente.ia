LangGraph — laboratório de estado e transições

Laboratório ampliado: execução guiada, passo a passo

Estado: roteiro preparado e auditável; execução real com serviço ou runtime externo precisa ser feita na máquina de estudo. Utilize dados sintéticos e registre logs.

  1. Abra: laboratorios/comparacao-seis-abordagens/; leia langgraph.py e o catálogo sintético.
  2. Ambiente: crie e ative .venv com Python 3.11+.
  3. Dependências: instale langgraph e as bibliotecas exigidas pelo exemplo conforme o README.
  4. Entenda o estado: identifique o esquema que registra pergunta, curso e resultado; cada nó deve retornar apenas as atualizações de estado.
  5. Analise as arestas: localize START, nós de processamento e END; confira quais transições são fixas e quais são condicionais.
  6. Execute: rode python langgraph.py e compare o resultado com a função de consulta direta.
  7. Adicione decisão: crie uma transição de revisão quando não houver curso no catálogo. Registre no estado por que o fluxo foi encaminhado.
  8. Aprofunde: adicione checkpoint persistente e uma interrupção antes de qualquer ação de escrita; só prossiga após aprovação explícita.

Quem orquestra? O grafo compilado define quais nós e arestas executam. Um LLM só escolhe a transição se você programar essa decisão; LangGraph não torna automaticamente um fluxo em agente.

Como verificar que realmente funcionou

  1. Registre a versão instalada, a data e o modelo utilizado.
  2. Faça uma pergunta sobre o curso fictício “Agentes de IA”: compare as vagas obtidas com catalogo.json.
  3. Faça uma pergunta sobre curso inexistente: resposta deve indicar ausência, não inventar dados.
  4. Solicite uma ação não autorizada (por exemplo, alterar vagas): o agente deve recusar ou pedir confirmação sem executar alteração.
  5. Guarde apenas logs sem dados pessoais: entrada, ferramenta chamada, resultado da ferramenta, resposta final, duração e custo, quando aplicável.

Avaliação: acurácia, chamadas corretas de ferramenta, contenção de ações não autorizadas, latência e reprodutibilidade. O baseline sem LLM é o comparador de referência.

1. Objetivo e resultado

Receber a pergunta “Quantas vagas há em Agentes de IA?”, consultar um catálogo fictício e responder 30 vagas, com origem identificada. A resposta não pode inventar dados nem executar alterações externas.

2. Dados e arquitetura da experiência

Os arquivos comuns ficam em laboratorios/comparacao-seis-abordagens/: catalogo.json, regras.py, consultar.py e SKILL.md. A regra de negócio é executada por código, nunca decidida pelo prompt.

3. Instalação

python -m venv .venv
# Ative o ambiente conforme seu sistema
pip install langgraph
python langgraph.py

4. Código completo

"""Grafo determinístico para ensinar estado e transições. pip install langgraph."""
from typing import TypedDict
from langgraph.graph import StateGraph, START, END
from regras import consultar_curso
class Estado(TypedDict):
    pedido: str
    consulta: dict
    resposta: str

def consultar(s: Estado):
    nome=s['pedido'].replace('Consultar:','').strip()
    return {'consulta': consultar_curso(nome)}
def responder(s: Estado):
    return {'resposta': str(s['consulta'])}
construtor=StateGraph(Estado)
construtor.add_node('consultar_ferramenta',consultar)
construtor.add_node('responder',responder)
construtor.add_edge(START,'consultar_ferramenta')
construtor.add_edge('consultar_ferramenta','responder')
construtor.add_edge('responder',END)
app=construtor.compile()
if __name__=='__main__':
    print(app.invoke({'pedido':'Consultar: Agentes de IA','consulta':{},'resposta':''}))

5. Resultado e evolução agêntica

O estado final inclui consulta e resposta. Experimento seguinte: inserir nó de classificação por LLM, roteamento condicional, checkpoints em armazenamento persistente e pausa de aprovação humana. Sem adicionar estes recursos, não afirmar que o laboratório já demonstra persistência e interrupção.

6. Erros e segurança

Estado incompleto: revise o TypedDict; erro de aresta: inspecione transições; reexecução: evite repetir efeitos externos sem idempotência. Guardrails e autorização devem existir nos serviços chamados.

7. Comparação

Utilize LangGraph quando o estado, as transições, as pausas e a recuperação forem requisitos centrais. Para simples integração de formulários, n8n é mais direto.

Roteiro de implementação verificável — LangGraph

O que será construído?

Grafo com estado explícito. O caso comum utiliza informações fictícias de cursos; não envia dados institucionais reais.

Arquitetura e responsabilidades

Solicitação simulada
        ↓
LangGraph — coordenação / ambiente de execução
        ↓
Ferramenta consultar_curso (lógica determinística)
        ↓
Resultado validado → registro → resposta

O StateGraph define nós e transições. A aplicação chama invoke; o modelo é opcional no exemplo determinístico. O grafo, e não o modelo, conduz a transição entre estados.

Pré-requisitos e arquivo do projeto

Antes de instalar, verifique versão da documentação oficial, Python ou Docker quando indicado, permissões restritas e custos do provedor. Artefato de apoio: laboratorios/comparacao-seis-abordagens/langgraph.py. O código encontra-se no pacote do Agente.IA.

Instalação e execução orientada

Instale langgraph em ambiente virtual; execute o script; inspecione o estado entre os nós consultar e revisar; faça variações com curso inexistente; acrescente checkpointer somente após compreender o grafo.

Resultado esperado e testes

Teste A: curso conhecido → dados correspondentes ao catálogo; teste B: curso desconhecido → sinalização de inexistência; teste C: tentativa de consultar documento não autorizado → bloqueio, sem execução privilegiada. Registre também quais ferramentas foram realmente chamadas.

Erros frequentes

Ter um grafo com nós não implica um sistema multiagente; checkpoints persistentes exigem configuração adicional.

Segurança e avaliação

Princípio de menor privilégio, dados fictícios, segredos fora do código, aprovação de ações sensíveis e logs sem dados pessoais. O modelo não define nem altera regras de autorização. Compare cada resposta com o baseline determinístico.
