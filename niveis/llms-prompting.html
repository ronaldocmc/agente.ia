N2 — LLMs e prompting

O que aprender: Modelos por API e locais, contexto, limites e custo. Experiência aplicada: Extrair informações de uma notícia e revisar.

Aprenda a separar instruções, dados não confiáveis, formato de saída e fontes. Compare uma chamada local com uma API comercial, quando disponível, sem confundir a geração de texto com execução de ações.

1. Conceitos para estudar

  • Contexto e prompting
  • Modelos com pesos disponíveis
  • Segurança de entrada

2. Tecnologias e por que consultá-las

Estas são opções para explorar, não uma lista de instalações obrigatórias. Consulte a ficha de cada tecnologia antes de adotá-la.

  • Ollama
  • Lumi-4B
  • Modelos por API

3. Laboratórios e atividades

  • Modelo local e primeiro agente
  • Plataformas prontas versus modelo local

4. Aplicações e estudos de caso

    5. Exercício guiado

    Use uma notícia fictícia com título, data e fonte; peça um JSON com tema, evidências textuais e campos ausentes. Compare com o gabarito e revise manualmente.

    Entregável: Prompt, JSON esperado, gabarito, erros observados e registro do modelo/versão.

    6. Critério de avanço

    Consegue distinguir informação extraída da fonte de inferência produzida pelo modelo.

    Registre os testes efetivamente executados, os erros encontrados e as dependências externas ainda não verificadas. Uma simulação não deve ser descrita como execução real de um runtime.
