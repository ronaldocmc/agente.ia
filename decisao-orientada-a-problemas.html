Comparar sem misturar camadas

Não compare n8n com Ollama como se fossem concorrentes: n8n integra processos, Ollama hospeda modelos. Compare Hermes, OpenClaw, Grok Bot e dots como alternativas de runtime/plataforma; compare CrewAI, Agents SDK e LangGraph como formas de construir ou coordenar lógica, sempre observando seus papéis específicos.

Aplicação completa: Escritório Virtual

Comece com Next.js (interface) → FastAPI (autenticação, políticas, APIs) → n8n (eventos e rotinas) + agente (seleciona ferramentas) → PostgreSQL (estado, dados, auditoria). O fluxo inicial é triagem → consulta autorizada → minuta → aprovação humana → registro. Não habilite envio ou alteração em sistemas reais antes de testar permissões.
