01

Conheça a tecnologia e o problema

Entenda controle de fluxo explícito, estado, nós e transições. O primeiro grafo não usa LLM: isso permite verificar o roteamento antes de acrescentar IA.

O desafio é atender dúvidas sobre cursos fictícios. Vamos usar a mesma base do exercício individual, sem dados da UNESP.

IDCursoVagas cadastradasInscrições
C001Introdução à IA30abertas
C002Agentes de IA25encerradas
C003Banco de Dados40abertas

O arquivo catalogo_sintetico_2026.json é a fonte. Vagas cadastradas não significa vagas restantes: observe que C002 está encerrado apesar de possuir 25 vagas nominais. Nenhum exemplo realiza inscrição ou altera dados.

Ao final, você deverá explicar por que a tecnologia foi escolhida, quem controla a execução, quem interpreta dados e quem autoriza uma operação.

02

Entenda a arquitetura

START→validar→consulta OU revisão→END
ComponentePapel
EstadoCampos compartilhados entre os nós.
NóFunção que lê estado e produz atualização.
Aresta condicionalSeleciona próximo nó conforme regra.

A figura representa o caminho deste exercício, não todas as capacidades do produto.

03

Prepare seu ambiente

Abra o Explorador de Arquivos e encontre a pasta Wiki_unespIA/laboratorios/tutoriais-tecnologia do pacote extraído. No Windows, abra-a e digite powershell na barra de endereço; pressione Enter. No Linux/macOS, use o terminal e cd para essa pasta. pwd (ou Get-Location) confirma a pasta. Os comandos deste tutorial são executados ali salvo indicação diferente.

Instale Python 3.11 ou superior compatível com a biblioteca que for usar, a partir de python.org. Verifique com python --version (Windows: py --version se necessário). Não rode os comandos no prompt interativo >>> do Python; use o terminal do sistema.

Python e ambiente virtual. O primeiro exercício não precisa de credencial nem modelo. Este é um grafo de workflow, ainda não um agente autônomo; a evolução poderá adicionar um nó LLM para interpretação de texto com validação posterior.

05

Faça a primeira execução

Comando / exemplo
python test_core.py
python core.py consultar C001
python core.py consultar Astrofísica

Como saber se funcionou? Os dez testes devem passar. C001 retorna status ok, 30 vagas e a fonte; Astrofísica retorna nao_encontrado; inscrição sem curso retorna esclarecer; alteração retorna negado. Não se trata ainda de um agente de IA.

Crie um grafo mínimo, observe um nó e o estado retornado.

ola_grafo.py
from typing import TypedDict
from langgraph.graph import StateGraph, START, END
class Estado(TypedDict):
    texto: str
g = StateGraph(Estado)
g.add_node('saudacao',lambda s: {'texto': 'Olá, '+s['texto']})
g.add_edge(START,'saudacao');g.add_edge('saudacao',END)
print(g.compile().invoke({'texto':'estudante'}))

Salve como ola_grafo.py; execute python ola_grafo.py.

Como saber se funcionou? A saída contém texto = Olá, estudante.
06

Construa o projeto completo, passo a passo

langgraph_cursos.py
"""Grafo determinístico. Não utiliza APIs de modelos; demonstra controle explícito."""
from typing import TypedDict
from langgraph.graph import StateGraph, START, END
from core import atender
class Estado(TypedDict, total=False):
    acao: str
    curso: str
    resultado: dict
    destino: str

def validar(s: Estado):
    return {'destino':'consulta' if s.get('acao')=='consultar' else 'revisao'}
def consulta(s: Estado):
    return {'resultado':atender('consultar',s.get('curso',''))}
def revisao(s: Estado):
    return {'resultado':atender(s.get('acao',''),s.get('curso',''))}
g=StateGraph(Estado)
g.add_node('validar',validar);g.add_node('consulta',consulta);g.add_node('revisao',revisao)
g.add_edge(START,'validar')
g.add_conditional_edges('validar',lambda s:s['destino'],{'consulta':'consulta','revisao':'revisao'})
g.add_edge('consulta',END);g.add_edge('revisao',END)
app=g.compile()
if __name__=='__main__':
    for entrada in [{'acao':'consultar','curso':'C001'},{'acao':'consultar','curso':'Astrofísica'},{'acao':'inscrever'},{'acao':'alterar','curso':'C001'}]:
        for evento in app.stream(entrada,stream_mode='updates'): print(evento)
        print('---')

Arquivo pronto: langgraph_cursos.py. Salve-o ou copie o conteúdo; mantenha o nome indicado.

O validador só determina o destino. A função consulta ou revisao chama a regra Python, e o grafo retorna ao END. A função stream apresenta eventos de atualização, não apenas a resposta final.

Comando / exemplo
python langgraph_cursos.py
Como saber se funcionou? O caso consultável atravessa validar → consulta. Pedido de inscrição/alteração atravessa validar → revisão. Nenhum LLM foi executado.
07

Personalize e amplie

Adicione uma nova rota explícita para o caso revisar. Como evolução, um nó de interpretação poderia retornar acao e curso a partir de texto livre; anterior à consulta, valide tipo, allowlist de ações e nome. Não autorize alteração com base na classificação do LLM. Estudo de persistência: um checkpointer registra estados para retomar uma execução; não é automaticamente RAG nem banco de fatos.

08

Automação, persistência e encerramento

O grafo é executado por script. Para eventos/agendamento, é preciso um serviço que invoque ou retome a aplicação. Não confunda uma aresta com um agente independente. Se usar interrupção para aprovação humana, teste a retomada com a versão documentada e não execute alterações reais.

10

Segurança e erros frequentes

Atenção. Use uma VM/usuário de laboratório, sem pastas pessoais compartilhadas, tokens institucionais, contatos, rede interna ou ações externas; se não puder assegurar o isolamento, execute apenas a etapa offline. Não conceda shell ou escrita para este problema. Use credenciais temporárias e limite de gastos. Uma instrução em linguagem natural nunca substitui um controle técnico no código, configuração ou sistema operacional.

Compare o arquivo do catálogo antes e depois dos testes. No Windows use Get-FileHash catalogo_sintetico_2026.json; Linux/macOS: shasum -a 256 catalogo_sintetico_2026.json (ou sha256sum). Hashes iguais mostram que o arquivo observado não mudou; não provam segurança completa. Não publique logs com chaves, identificadores de sessão ou tokens.

ProblemaComo investigar
SintomaDiagnóstico
ImportErrorConfira langgraph no ambiente.
Rota inválidaConfira se retorno de validar está no mapeamento de arestas.
Campo faltanteConfira TypedDict e .get; entradas incompletas devem ser tratadas.
Loop sem fimRevise arestas e limites do grafo; neste exemplo toda transição termina.
11

Avalie e documente

Meça: percentual de casos aprovados (aprovados ÷ executados × 100), chamadas de ferramenta, tempo de resposta, tentativas bloqueadas e intervenções humanas. Registre modelo, versão, data, hardware e configuração. Se houver API, estime custo com o S01 — Custos. Use o S04 — Multiagentes quando comparar equipe e execução paralela. Não compare tempos sem manter hardware, dados e condições constantes.

Entregue: repositório sem segredos, arquivos necessários, README de reprodução, diagrama indicando quem orquestra e quem autoriza, CSV preenchido e uma breve análise do que falhou. A apresentação individual e os cinco desafios setoriais continuam no enunciado abaixo.

Objetivo da tecnologia: Mostrar que orquestração é controle explícito de estado, transições e decisões.

1. Fundamentação e preparação

Explique por escrito o que é LangGraph, o problema que resolve, se oferece runtime, framework, SDK ou workflow e por que isso importa. Diferencie a ferramenta do modelo de linguagem.

Instalação e ambiente

  1. Crie ambiente virtual Python.
  2. Execute `pip install langgraph`.
  3. Prepare entradas sintéticas e um módulo Python com estado tipado.

Resposta estruturada, log e revisão humana quando cabível

Desenhe o fluxo real de sua implementação, identificando onde está a orquestração, quem decide ferramentas e quais verificações são determinísticas. O diagrama acima é um ponto de partida, não uma descrição completa do produto.

3. Construção passo a passo

  1. Defina TypedDict com `solicitacao`, `curso`, `resultado`, `revisao` e `historico`.
  2. Implemente funções de nós para classificar, consultar, revisar e responder.
  3. Crie `StateGraph`, conecte nós e defina condições de roteamento.
  4. Execute o grafo com cinco entradas e compare o estado de entrada/saída.
  5. Na extensão, adicione um nó LLM e checkpoints se a versão e armazenamento utilizados suportarem.

Comandos ou ponto de partida

python -m venv .venv
python -m pip install langgraph

LangGraph não é um LLM; é um mecanismo de orquestração orientada a grafos.

5. Segurança, memória e modelo

Não conceda acesso a sistemas institucionais, rede interna, contas pessoais ou edição de dados reais. Registre exatamente o que o agente pode ler/escrever; diferencie contexto da conversa, memória persistente e base documental. O modelo não substitui autorização. Se usar LLM local, informe nome/versão, RAM/VRAM, quantização, velocidade e se suporta tool calling.

6. Entrega individual

  1. Apresentação de 20–25 minutos, com demonstração do sistema, explicação do orquestrador e pergunta inesperada.
  2. Repositório com código/configurações exportáveis, dados sintéticos, README e instruções reproduzíveis.
  3. Fluxograma real, incluindo ferramenta, LLM, dados, memória, logs e autorizações.
  4. CSV com cinco testes e evidências, incluindo erro e tentativa de alteração não autorizada.
  5. Relatório de 2–4 páginas com comparação de duas alternativas, dificuldades e evolução proposta.
