Grafo navegável do ecossistema de agentes

Quer explorar por uma pergunta? Abrir o explorador de perguntas e relações · Para selecionar tecnologias no próprio mapa, use “Explorar tecnologias”.

Classificação unificada: modelos geram; runtimes executam agentes; frameworks estruturam decisões; workflows integram processos; ferramentas e dados dão suporte. Conhecer os dez grupos · Ver escolhas por requisito · Executar os laboratórios.

Além do mapa: conteúdos preservados

O grafo simplifica as relações, mas não substitui as fichas completas nem os estudos de caso detalhados.

Explore o ecossistema por relações arquiteturais: tecnologias, categorias, conceitos, etapas, laboratórios e estudos de caso. Use a visão resumida para orientação; ative “catálogo completo” para visualizar todas as fichas. As relações são curadoria didática, não certificação de compatibilidade.

Como usar para aprender: selecione uma tecnologia (por exemplo, n8n, LangGraph, OpenClaw ou Agents SDK). À direita, siga o percurso Entender → Relacionar → Comparar → Implementar → Aplicar. Em “Relações”, use ◎ para selecionar outro nó sem sair do grafo.

Catálogo auditado: todas as 169 fichas de tecnologias estão indexadas no grafo. O modo inicial exibe uma seleção para facilitar a leitura; ative “Todas as 169 tecnologias” para mostrar o catálogo inteiro ou pesquise qualquer ficha pelo nome.

Explorar tecnologias

Pesquise uma ferramenta ou abra uma área de conhecimento. Selecione uma tecnologia para destacar suas relações no mapa.

Explore uma tecnologia pelo botão “Explorar tecnologias”. Use roda do mouse para zoom, arraste para mover e clique em um nó para abrir detalhes. O painel direito pode ser recolhido.

Como navegar

Selecione um nó para ver seu papel, usos, limitações e relações com outras páginas.

Para começar: pesquise OpenClaw, Hermes, dots, Ollama ou Observar.IA.

Exploração prática: laboratório n8n · automação ou agente? · laboratórios avançados · todos os estudos de caso. Pesquise n8n ou selecione Laboratórios para explorar as novas conexões.

Visualização inicial simplificada: grupos didáticos, ferramentas principais e laboratórios. Para explorar todas as fichas, marque Mostrar catálogo completo. Ao selecionar um nó, o painel direito mostra o significado e seus vínculos. Pesquise um nome para localizar tecnologias específicas. Alterne a visualização entre modo didático hierárquico, orgânico, radial, por camadas e por categorias.

Como interpretar o grafo

Conectado a não significa necessariamente “compatível de fábrica”. Arestas como usa, suporta, alternativa a, experimentado em e classificado em têm significados diferentes. Compare sempre a documentação, licenças, política de segurança e versões.
