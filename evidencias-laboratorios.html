Padrão de evidência

Preencha o MODELO_REGISTRO_EXECUCAO.md no diretório do laboratório com hardware, software, modelo, identificador e versão da tecnologia, comandos, parâmetros, testes, evidências e limitações. Nunca publique tokens, senhas ou dados pessoais.

Verificação do pacote

O script auditar_wiki.py verifica referências relativas de páginas e arquivos. É um teste estrutural, não uma certificação de funcionamento dos agentes. Execute python auditar_wiki.py na pasta raiz do Agente.IA.

Validação executável — etapa inicial

Execução registrada em 2026-11-14T11:34:21.830907+00:00, Python 3.13.5, Node v22.16.0. Foram aprovados 14 grupos: 62 verificações contabilizadas (incluindo testes simulados, sem contar subtestes separadamente), além da listagem do dataset de LLMs.

Para começar, instale Python 3.10+ e Node.js; na raiz do ambiente execute python -m pip install pytest e python laboratorios/validar_laboratorios.py. O script não instala runtimes nem acessa serviços externos. O resultado é salvo em JSON.
