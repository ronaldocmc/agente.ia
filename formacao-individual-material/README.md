# Kit da formação individual em agentes de IA

Abra `../formacao-individual.html` no site.

- `baseline.py` e `test_baseline.py`: programa determinístico com cinco testes sem chamadas externas.
- `catalogo_sintetico_2026.json`: base fictícia comum.
- `cenarios_de_teste.csv`: cinco situações para registrar resultados.
- `rubrica_individual.csv`: critérios e pesos da avaliação formativa.
- `MODELO_README.md`: modelo de repositório individual.
- `MODELO_RELATORIO.md`: modelo de relatório breve.
- `MODELO_APRESENTACAO.md`: roteiro de 20–25 minutos.
- `ENUNCIADO_DOCENTE.md`: enunciado atribuído a cada aluno.

Execute localmente: `python -m unittest discover -s . -p test_baseline.py -v` a partir deste diretório.

Não usar dados reais da FCT/UNESP nem credenciais em repositórios.
