Exemplo: Observar.IA

Entrada: indicação de fonte por formulário/WhatsApp → n8n pode receber eventos → serviço Python verifica autorização → Ollama + modelo local ou API processam o texto → LangGraph pode manter estado quando houver pausas e retornos → PostgreSQL registra evidências → curador aprova → distribuição externa. Camadas são alternativas e complementos conforme requisitos.

Exemplo: assistente pessoal

OpenClaw ou Hermes podem executar funções de assistente auto-hospedável; dots representa agente gerenciado em nuvem. Escolha considerando canais, identidade, custo, privacidade, políticas e capacidade de migração.
