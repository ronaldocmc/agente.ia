# Do grafo à implementação

1. Abra `grafo.html`, procure uma tecnologia e clique no nó.
2. Leia o percurso no painel direito: Entender, Relacionar, Comparar, Implementar e Aplicar.
3. Nas tecnologias com laboratório curado há um link direto para a implementação.
4. Os demais nós exibem um caminho geral para os laboratórios, sem fingir que possuem laboratório próprio.
5. Na lista de relações, use o botão ◎ para trocar o nó selecionado ou o link de título para abrir a página.

Atenção: links para materiais não garantem que um runtime tenha sido executado. Confirme o status dos testes na documentação de cada laboratório.
