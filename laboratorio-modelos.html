Laboratório de comparação de modelos locais

Compare modelos como Gemma, Llama e Lumi com o mesmo conjunto de tarefas, registrando condições de execução. Um modelo é o componente que interpreta ou gera conteúdo; o Ollama disponibiliza modelos locais por uma API, enquanto n8n, LangGraph e outros sistemas coordenam a execução do agente.

Implementação passo a passo

  1. Instale Python 3.10+ e Ollama; confirme que ollama list funciona.
  2. Escolha dois ou mais modelos realmente disponíveis e compatíveis com seu computador. Para Gemma e Llama, use os identificadores exibidos por ollama list. Para Lumi, confirme primeiro a disponibilidade e a forma de execução no seu ambiente; não presuma suporte nativo no Ollama.
  3. Abra um terminal no diretório laboratorios/fases-aprendizagem e execute python comparar_llms.py --list para validar entradas sem chamar nenhum modelo.
  4. Quando houver modelos locais disponíveis, execute python comparar_llms.py --models NOME1 NOME2, substituindo pelos identificadores instalados.
  5. Consulte resultados_llms.csv e resultados_llms.json. Compare as respostas e preencha manualmente a coluna de avaliação semântica.
  6. Repita a execução, registrando memória, hardware e temperatura; compare estabilidade e tempo. Não conclua que um modelo é superior por um único teste.

Cuidados

Use apenas dados fictícios. Uma resposta do LLM não deve executar ferramentas com acesso real a sistemas. O experimento de classificação não demonstra capacidade de tool calling, memória ou autonomia agêntica.

Arquivos do laboratório

comparar_llms.py, tarefas_llm.json, README.md, testes_formacao.py. O script usa somente a biblioteca padrão do Python e a API local do Ollama.
