Laboratórios avançados: aprenda a construir e comparar agentes

Automação e n8n: entenda workflow × agente · construa o primeiro workflow n8n · 12 estudos de caso.

Não é necessário dominar todas as tecnologias. Comece com o primeiro agente e, depois, construa o mesmo cenário em arquiteturas diferentes. As páginas seguem um roteiro idêntico: instalação, arquitetura, código, execução, resultados, erros, segurança, avaliação e alternativas.

1. Qual laboratório escolher?

LaboratórioFocoQuando vale a penaDependências
CrewAI — equipe de agentes especializadaEquipes de analista e revisorUse CrewAI para divisão de responsabilidades e colaboração entre especialistas; não é necessário para um único cálculo ou fluxo fixo.conta/modelo ou runtime externo opcional
LangGraph — grafo de execução com estadoEstados, transições e retomadaEscolha LangGraph quando transições, checkpoints, auditoria e interrupções importam mais que rapidez de configuração.sem LLM no exercício principal
Hermes Agent — assistente com skills e ferramentasAgente extensível e memóriaUse Hermes para estudar runtime de assistente com terminal, memória e skills, tendo acesso ao ambiente e capacidade de isolamento.conta/modelo ou runtime externo opcional
OpenClaw — Gateway, canais e skillsAssistente multicanal auto-hospedávelEscolha OpenClaw quando canais, sessões e Gateway próprios forem requisitos centrais; avalie controle e superfície de ataque.conta/modelo ou runtime externo opcional
Grok Bot — Bots persistentes e colaboraçãoEquipe de agentes gerenciadosUse Grok Bot para experimentar colaboração persistente rapidamente, aceitando a dependência de plataforma gerenciada.conta/modelo ou runtime externo opcional

2. Preparação sem dependência comercial

Abra README do projeto. Teste o domínio sem LLM:

cd Wiki_unespIA/laboratorios/avancados
python testes.py
python baseline.py

O cenário utiliza arquivos sintéticos. O exercício LangGraph demonstra grafo com estado sem LLM; CrewAI, Hermes, OpenClaw e Grok Bot exigem ambiente externo para executar os componentes específicos.

4. Protocolo científico comum

Faça 20–50 entradas sintéticas por abordagem: consulta normal, fonte ausente, erro, permissão negada e instruções adversariais. Meça taxa de resolução, tempo, custo, estabilidade, rastreabilidade, incidentes e esforço de configuração. Versões e resultados externos devem ser coletados em cada ambiente.
